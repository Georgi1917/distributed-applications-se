## Описание на проекта
Проектът представлява Job Listing система, която съдържа Фирми, Обяви за работа, Потребители, Технологии. Потребител с роля "ADMIN" може да добавя, изтрива и променя съществуващи фирми, обяви, други потребители и технологии, също може да закача технологии към дадена обява и да премахва кандидатурите на други потребители. Потребители с роля "USER" могат да разглеждат всички данни и да кандидатстват за дадена обява. Не регистрирани потребители имат правото само да разглеждат данни. 

## Инструкции за стартиране
Spring Boot проектът може да се стартира, като влезнете в папката JobListing, отворите команден терминал и напишете "mvnw spring-boot:run", Front end-ът може да се стартира, като влезните в папката FrontEnd/, отворите команден терминал и напишете "npm run dev", за да работи правилно проектът трябва да имате версия 21 на Java SDK инсталирана.
